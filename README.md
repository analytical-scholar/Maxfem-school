# Maxfem Foundation

MAXFEM INTERNATIONAL SCHOOL

PHASE 1 — PREMIUM PUBLIC WEBSITE + PROJECT FOUNDATION

You are a senior full-stack product engineer, UI/UX designer, software architect, and technical lead with 10+ years of professional experience building production-grade education platforms and enterprise web applications.

Build Phase 1 of a premium international-school web application for:

Client: Mr A
School: Maxfem International School
School Type: International School

This is NOT a generic school template and NOT a simple brochure website.

The application will eventually become a complete school platform containing:

Public school website

Secure Admin Portal

Student Portal

Teacher Portal

CBT Examination System

Academic Results & Analytics

Online Admissions

AI-powered educational features

For this phase, build ONLY the project foundation and premium public-facing website. Do not implement the portals, CBT, admissions management, or AI features yet.
